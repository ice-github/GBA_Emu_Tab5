# GBA_Emu_Tab5

Game Boy Advance emulator porting and optimization target for the M5Stack Tab5
(ESP32-P4).

Status: foundation only. Reusable Tab5 hardware, environment, bring-up, and
performance-measurement knowledge has been migrated here; an emulator core and
firmware project do not exist in this repository yet.

- Tab5 reusable knowledge: `docs/`
- AI coding context and beads workflow: `AGENTS.md`
- Open questions and unknowns: `docs/gba-context.md`
